Module Dependencies

Can you deploy one module without the others?

Yes — with one universal rule and a few module-specific caveats. The universal rule: every module requires the H1 shared platform enablers (HITL framework, XAI layer, Pub/Sub fabric, Firestore, BigQuery audit trail) to be live before it can deploy. That's it. Beyond that, each module's specific prerequisites are listed below.

Universal prerequisite
H1 Shared Enablers must be live before any module deploys. HITL Framework · XAI / SHAP Layer · Pub/Sub Event Fabric · Firestore State Store · BigQuery Audit Trail · VPC-SC Perimeter · CMEK · IAM / Workload Identity. This is why Data Governance and the platform infrastructure are Horizon 1 — they are not optional prerequisites, they are prerequisites.
M-01 · Commercial · H3
CCAI Sales Agent
Can deploy standalone
Needs H1 shared enablers only. No ML Feature Store dependency — the agent is conversational, not model-driven.
Soft link to M-02: ContractGuard handles contract review post-qualification. Without it, contracts route to Legal manually — the agent still works.
M-02 · Commercial · H2
ContractGuard
Can deploy standalone
H1 shared enablers + partial Data Governance (contract metadata features in Feature Store). Can run with reduced accuracy before Feature Store is fully populated.
No cross-module dependency. Fully self-contained. Does not depend on RevRec AI or any other domain module at runtime.
M-03 · Financial · H2
RevRec AI
Can deploy standalone
H1 shared enablers + Data Governance (contract features are primary model inputs — EU AI Act Art. 11 requires feature lineage). SAP integration required for the GL write.
Soft link to M-02: ContractGuard enriches the feature set. Without it, RevRec AI reads contract data directly from Salesforce — slightly lower feature richness but fully operational.
M-04 · Financial · H2
FinRisk Sentinel
Can deploy standalone
H1 shared enablers + Data Governance (financial features from Feature Store gate the anomaly model). BigQuery streaming inserts must be live.
No cross-module dependency. Operates on financial events independently of CommercialART modules. Shares the platform layer only.
M-05 · Operations · H2
Asset IQ
Can deploy standalone
H1 shared enablers + Data Governance + unified telemetry pipeline. Asset IQ is blocked until the 6-region schema is validated by Data Governance — this is a hard dependency, not a soft one.
No cross-module dependency. Operationally isolated from Commercial and Financial modules.
